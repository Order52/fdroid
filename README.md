# TinyKit F-Droid repo

Official [TinyKit](https://github.com/Order52/tinykit) builds as an F-Droid repository.
Open **https://order52.github.io/fdroid/** on your phone and tap *Add*.

Repository address: `https://order52.github.io/fdroid/repo`
Fingerprint (SHA-256): `DF8806214799828EF5D7D11FD62D101FE0239D43B85964A23449EC66222A3011`

The APKs are the same files as the GitHub Releases, signed by the developer. Only the repo index is signed with the repo key.
`update.sh` adds the newest release (needs the repo key, which isn't in this repository).
